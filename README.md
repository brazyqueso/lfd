# LFD — LLMs for Dummies

**Made by Pakun**

Terminal menu that gets a local LLM running on Kali. No API key.

- `[OS controlled]` = uncensored agent-style models
- `[Chat only]` = normal chat models

## Install on Kali

```bash
curl -fsSL https://raw.githubusercontent.com/brazyqueso/lfd/main/install.sh | bash
source ~/.bashrc
lfd
```

Then pick **GET ME AN LLM**.

## Commands

```
lfd
lfd wizard
lfd status
lfd chat
lfd pull qwen2.5-coder:7b
```
